      How the assets move together (correlation)

      Method: monthly Monte Carlo with 1,000 lognormal paths using the portfolio's expected return and volatility (from the correlation matrix). A fixed random seed keeps results stable between clicks. Offshore assets are measured in rand, so their returns include currency moves. Index and active funds in the same asset class share the class return assumption; only their costs differ. Your income and the tax tables are assumed to rise with inflation, so tax is worked out in today’s rand with the 2026/27 tables.
